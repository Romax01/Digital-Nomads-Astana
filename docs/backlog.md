# Оставшиеся задачи и известные ограничения

## Проверки и качество

- Автоматизированный сквозной тест браузера (Playwright) не написан. Интерфейс проверен вручную в Chrome.
- Отрисовка в браузере измерена только в фоновой вкладке (до обновления DOM, p95 35 мс). Замер до кадра отрисовки в активной вкладке на стенде не выполнялся.
- Планировщик работает в процессе backend: построение модели CP-SAT занимает GIL и даёт пики задержки realtime до ~0,5 с во время пересчёта. Нужно вынести его в отдельный процесс.
- Первая загрузка рабочего сценария занимает ~25 с (оптимизация начального плана); в это время обновления приостанавливаются. Повторные загрузки идут из кэша.
- Восстановление брокера MQTT проверяется вручную (перезапуск контейнера `mqtt`), а не в pytest.
- Полный аудит доступности (экранные дикторы, контрастность по WCAG) не проводился.
- Адаптер внешней LLM (`app/services/llm.py`) не тестировался с реальным ключом; по умолчанию выключен.

## Модель и планирование

- Упрощённая технология: состав перемещается целиком, сортировка по назначениям, тяговые расчёты и враждебность маршрутов по сигналам не моделируются.
- CP-SAT не учитывает транзитное занятие главного пути в маршрутах; это проверяет валидатор, и план с таким нарушением не предлагается.
- Альтернатива «изменить очередь» рассматривает перестановку одного поезда; комбинации нескольких перестановок не перебираются.
- Соседние станции — упрощённое состояние без собственного планирования.
- Нет произвольной задержки поездов на подходе. Задержки возникают от инцидентов, ожидания ресурсов и сценариев.
- Ремонт вагона без депо (малая станция) не моделируется: конфликт требует решения диспетчера.

## Архитектура и эксплуатация

- Один процесс backend: для горизонтального масштабирования нужно вынести движок, приём телеметрии и hub в отдельный процесс, а внутреннюю шину заменить на межпроцессную (`LISTEN/NOTIFY` или брокер).
- TLS для MQTT только подготовлен в конфигурации (закомментированный слушатель 8883), сертификаты не выпускаются.
- Токены пользователей хранятся в sessionStorage, отзыва токенов нет; управление пользователями через API не реализовано (только демо-учётки).
- Реальные интеграции (АСУ, датчики) отсутствуют — только контракт и адаптерный путь `source_mode = real`.
- Сертификация и соответствие требованиям безопасности движения — вне рамок MVP.

## Интерфейс

- Перетаскивание операций мышью на Ганте не реализовано: перенос выполняется через диалог «Перенести операцию» с серверной проверкой.
- Подписи в 3D — DOM-слои; при очень сильном отдалении камеры могут перекрываться.
