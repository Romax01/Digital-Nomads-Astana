# Индекс эффективности станции

Реализация — `backend/app/services/index.py`, конфигурация по умолчанию — `DEFAULT_INDEX_CONFIG` в `backend/app/sim/seed.py`.

## Формула

**I = 100 × Σ(wᵢ · sᵢ) / Σwᵢ**, где sᵢ ∈ [0; 1] — нормализованная оценка составляющей, wᵢ ≥ 0 — вес, Σwᵢ > 0.

Суммы берутся только по составляющим, для которых есть данные: отсутствующая составляющая исключается и из числителя, и из знаменателя. Благоприятное значение вместо отсутствующего измерения не подставляется. Качество оценки — доля веса с данными: 100 % — «Полная», ≥ 60 % — «Частичная», иначе «Низкая». Список отсутствующих составляющих показывается рядом с индексом.

Индекс — аналитический показатель, а не разрешение на движение: жёсткие ограничения проверяются независимо от него.

## Составляющие

| Ключ | Составляющая | Единица | Окно | Нормализация sᵢ | Источник |
|---|---|---|---|---|---|
| throughput | Пропускная способность | ваг./ч | 240 мин | min(1, факт / цель), цель 90 ваг./ч | журнал операций: завершённые техосмотры |
| schedule_deviation | Среднее отклонение от графика | мин | 240 мин назад + 1 ч прогноза | max(0, 1 − среднее / 45 мин) | фактические и прогнозные отправления относительно расписания |
| track_utilization | Загрузка путей парка А | доля путей | текущий момент | 1 в целевом диапазоне 0,45–0,80; линейно до 0 при 0 и при 1,0 | телеметрия рельсовых цепей, только актуальные данные |
| route_conflicts | Конфликты маршрутов и занятости | шт. | текущий прогноз | max(0, 1 − n / 8) | детектор конфликтов (пересечения путей, маршрутов, операции на закрытых путях) |
| idle | Простой локомотивов и бригад сверх резерва | доля смены | 120 мин | 1 − max(0, простой − резерв) / (1 − резерв), резерв 0,25 | журнал операций и смены |

Почему так:
- **Загрузка не «чем больше, тем лучше».** Перегрузка парка снижает оценку так же, как простой путей.
- **Необходимый резерв не штрафуется.** Простой в пределах резерва (25 % смены) — норма, штрафуется только избыточный простой.
- **Загрузка путей считается только по актуальным данным.** Если достоверные данные есть меньше чем по половине путей, составляющая не оценивается.

## Веса и пороги по умолчанию

| Параметр | Значение |
|---|---|
| Веса | пропускная способность 0,25; отклонение от графика 0,25; загрузка путей 0,20; конфликты 0,15; простой 0,15 |
| «Норма» | I ≥ 75 |
| «Внимание» | 50 ≤ I < 75 |
| «Критично» | I < 50 |

Веса, параметры нормализации и пороги меняются в «Настройках» без перекомпиляции (роль «Администратор», `PUT /api/v1/index/config`). Каждое сохранение проверяется (веса ≥ 0, сумма > 0, 0 ≤ «Внимание» < «Норма» ≤ 100, корректный диапазон загрузки, резерв в [0; 1)). Затем создаётся новая версия `index_configs`, а изменение пишется в аудит со значениями «было/стало». Значение индекса хранится вместе с версией конфигурации (`index_snapshots.config_version`).

## Что показывает интерфейс

Текущее значение и категорию, динамику (последние 40 точек, снимок каждые 15 с), три главных фактора снижения в баллах (wᵢ · (1 − sᵢ) / Σw · 100), время и окно расчёта, качество оценки, прогноз индекса для каждого предложенного плана.

## Прогноз индекса для плана

`compute_plan_index` оценивает ближайшие 4 ч по расчётным данным плана: вагоны с техосмотром, завершающимся в окне; средняя задержка отправлений; загрузка парка А по плану; оставшиеся конфликты. Простой в прогнозе не оценивается (качество «Частичная»), и это видно в интерфейсе.

## Пример 1 — все данные есть

| Составляющая | Значение | sᵢ | wᵢ · sᵢ |
|---|---|---|---|
| Пропускная способность | 72 ваг./ч | 72/90 = 0,80 | 0,25 · 0,80 = 0,200 |
| Отклонение от графика | 9 мин | 1 − 9/45 = 0,80 | 0,200 |
| Загрузка путей | 5 из 6 = 0,833 | (1,0 − 0,833)/(1,0 − 0,8) = 0,833 | 0,20 · 0,833 = 0,167 |
| Конфликты | 2 | 1 − 2/8 = 0,75 | 0,15 · 0,75 = 0,113 |
| Простой | 40 % при резерве 25 % | 1 − 0,15/0,75 = 0,80 | 0,120 |

I = 100 · 0,799 / 1,00 = **79,9 — «Норма»**, качество «Полная». Главные факторы снижения — пропускная способность и отклонение от графика (по −5,0 балла), затем конфликты (−3,8) и загрузка путей (−3,3).

## Пример 2 — нет актуальных данных по путям

Те же значения, но рельсовые цепи большинства путей не передают данные — составляющая «загрузка путей» исключается.

I = 100 · (0,200 + 0,200 + 0,113 + 0,120) / (1,00 − 0,20) = 100 · 0,633 / 0,80 = **79,1 — «Норма»**, качество «Частичная (80 % весов)», в списке отсутствующих — «Загрузка путей приёмо-отправочного парка». Индекс не завышается подстановкой s = 1 для отсутствующей составляющей.
